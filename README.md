# 🌴 Шаблон сайта туристического агентства

🔗 **Онлайн демо (Live Demo):** [https://template-1-nine-eta.vercel.app/](https://template-1-nine-eta.vercel.app/)

Современный, сверхбыстрый и SEO-оптимизированный лендинг для туристического агентства, разработанный на базе **[Astro](https://astro.build/)** с акцентом на высокую конверсию, соответствие **152-ФЗ** и высокую оценку **в Google PageSpeed Insights**.

---

## ✨ Ключевые особенности

- ⚡ **Zero-JS по умолчанию**: статический HTML без тяжелых клиентских фреймворков для мгновенной загрузки.
- 📱 **100% Адаптивность**: продуманный мобильный UX, выдвижное меню, быстрый скролл наверх и плавающая кнопка мессенджеров (MAX, Telegram, ВКонтакте).
- 🔍 **SEO & Метаданные "из коробки"**:
  - Микроразметка **Schema.org** (`TravelAgency` и `WebSite`).
  - Метатеги **Open Graph** и **Twitter Cards** для красивых карточек в соцсетях и мессенджерах.
  - Гео-теги и канонические ссылки (`canonical`).
- 🔒 **Полное соответствие 152-ФЗ и GDPR**:
  - Готовые страницы «Политика конфиденциальности» (`/privacy`) и «Согласие на обработку персональных данных» (`/consent`).
  - Интерактивный Cookie-баннер с гранулярным выбором и возможностью изменения настроек из футера.
- 🎨 **Оптимизация медиа**: автоматическая конвертация изображений в WebP через `astro:assets` и `sharp`.
- 💬 **Формы захвата заявок**: модальные окна бронирования и подбора тура с защитой от спама и маской ввода.

---

## 🛠️ Стек технологий

- **Фреймворк**: [Astro 5](https://astro.build/)
- **Язык**: TypeScript
- **Стили**: Модульный CSS / PostCSS (`autoprefixer`, `cssnano`)
- **Графика и иконки**: Оптимизированные WebP и встроенный SVG

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
npm install
```

### 2. Запуск сервера для разработки

```bash
npm run dev
```

Локальный сайт откроется по адресу `http://localhost:4321`.

### 3. Сборка для продакшена

```bash
npm run build
```

Скомпилированные статические файлы будут сохранены в папку `dist/`.

Для локального тестирования готовой сборки выполните:

```bash
npm run preview
```

### 4. Проверка типов (TypeScript)

```bash
npm run lint
```
